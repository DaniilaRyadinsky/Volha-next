# FSD structure

This directory follows Feature-Sliced Design.

- `app` - app initialization, providers, global app configuration.
- `pages` - page compositions used by Next routes from `../app`.
- `widgets` - large page blocks assembled from features and entities.
- `features` - user actions and business scenarios.
- `entities` - business entities and their model/ui/api.
- `shared` - reusable infrastructure, UI primitives, utilities, config, assets.
